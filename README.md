
# BOOKADOW

### Your Ideas. Beautifully Bound.

BOOKADOW is a professional book-writing and publishing application designed for Android and iOS.

## Main Features

- Create and manage multiple books.
- Organize books into chapters.
- Professional rich-text writing editor.
- Automatic table of contents.
- Standard publishing page sizes.
- Custom page formatting and typography.
- Front cover, back cover and spine designer.
- Automatic page numbering.
- Professional PDF book export.
- Offline writing and cloud backup.
- Import and export book documents.

## Technology

- Flutter
- Dart
- Firebase
- SQLite
- Material 3
